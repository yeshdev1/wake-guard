# Implementation Status

This file tracks **every** backlog task.

- **Task index** (below, generated) — all backlog tasks with status, an owner
  placeholder, and an evidence link. Generated by `scripts/task_tracking.py`;
  do not hand-edit the structural columns (Title/Epoch/Depends).
- **Detailed evidence log** — the full evidence narrative for active/completed tasks.

Rules:

- Status lifecycle: **Not started → In progress → In review → Complete** (or **Blocked**).
- **Status changes require acceptance evidence:** a task may enter In progress / In
  review / Complete only with an evidence link (commit, CI run, or a Detailed evidence
  log entry). Enforced by `scripts/task_tracking.py --check` (run by `make check-tracking`
  and `make ci`).
- A task is **Complete** only when every acceptance criterion passes.
- **Owner** is a placeholder (`_unassigned_`) until assigned.
- After editing `docs/BACKLOG.md`, run `python3 scripts/task_tracking.py --generate`.
